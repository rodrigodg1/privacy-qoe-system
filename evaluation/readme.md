

### Evaluation Repository Overview

This section contains various components for evaluating:

- **[fhevmjs-deploy-transactions](fhevmjs-deploy-transactions/)**  
    Scripts and configurations for deploying contracts and transactions.

- **[fhevmjs-local-encryption](fhevmjs-local-encryption/)**

- **[node](node/)**  
    Experiments and tests based on Node.js.

- **[Rust](Rust/fhe-evaluation)**

    Components and experiments built using Rust.
